# Cert4Update
Утилита для формирования списка сертификатов электронной подписи, подлежащих продлению в ближайшее время.
Выводит список сертификатов из заданного каталога и его подкаталогов, срок действия которых истекает в ближайшие дни (по умолчанию 60 дней).
Требования к окружению: OS Windows 10+, .NET 10

РАЗВЕРТЫВАНИЕ:
1. Загрузите установочный комплект из каталога Setup
2. Запустите на выполненение файл Setup.exe
3. В диалоге установщика укажите каталог установки программы и доведите установку до завершения
4. В каталоге программы откройте файл appsettings.json и в нем укажите каталог в котором расположены Ваши сертификаты, и срок в днях до окончания действия сертификата, который необходимо обновить:

{

  "CertDir": "..\\\\", # здесь укажите каталог с сертификатами, используйте двойной разделитель каталогов
  
  "MaxDaysToCertEnd": 60 # здесь количество дней до истечения срока действия сертификата
  
}

5. Сохраните изменения


ИСПОЛЬЗОВАНИИЕ:
Запустите программу Cert4Update.Console.exe. Результатом ее работы будет EXCEL файл со списком сертификатов ЭП, которые нужно продлять
